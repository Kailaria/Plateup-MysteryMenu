# Menu of Mastery

This PlateUp mod is a Dish mod where the foods that customers will order will change every day to match what ingredients are provided across the entire restaurant.

This Dish is inspired in part by:
* TV cooking competition shows like Chopped, Master Chef, Hell's Kitchen, etc.
* PlateUp's Fish dish (for the provider ideas)
* Overcooked's final boss missions across the series & DLCs
